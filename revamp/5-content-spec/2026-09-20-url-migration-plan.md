# 舊 URL 與新站 URL 處理計畫（草案）

版本：0.1（2026-09-20）  
狀態：SEO 與路徑規劃；尚未建立 redirect 或修改部署設定。

## 1. URL 處理原則

| 類型 | 處理方式 | 適用條件 |
| --- | --- | --- |
| 新站仍提供相同資訊 | 保留或建立對應 URL | 內容重寫後仍服務相同搜尋意圖 |
| 舊內容改成新定位 | 301 到新站對應頁 | 舊頁有外部引用或搜尋價值，且有清楚替代頁 |
| 歷史資料保留但不作現行入口 | 歷史索引、必要時 noindex | 有查證或回顧價值，不應成為招生主張 |
| 私密／內部資料 | 不進公開 sitemap | 僅管理員保存或受限調閱 |
| 沒有替代內容且無保存價值 | 410 或移除 | 必須先確認沒有重要外部連結與法定保存需求 |

## 2. 第一批重要路徑

| 舊來源 | 新站候選目的地 | 初步處理 | 原因與驗收 |
| --- | --- | --- | --- |
| `/`（舊首頁） | `/` 共學營首頁 | 重寫後保留 | 網站主入口；必須清除舊免費／開源社群主張 |
| `/faq` | `/faq` 或 `/camp/faq` | 重寫後保留或集中 | 需清楚分開公開內容、會員、課程費用與討論區權限 |
| `/about`、`/about/intro` | `/association` 或 `/about/association` | 301 候選 | 協會仍是主辦者，但頁面角色改為主辦者介紹 |
| `/about/cooperation` | `/association/history/cooperation` 或歷史索引 | 歷史保存／改寫 | 舊合作頁含「不收費」直接衝突，不能原樣保留 |
| `/about/activities/*` | `/history/activities/*` 或歷史索引 | 歷史保存候選 | 避免歷史活動被誤讀為目前課程或現行服務 |
| `/about/members/*` | `/history/people/*` 或受限保存 | 逐頁判定 | 需本人資料更新與公開同意 |
| `/about/internal/*` | 無公開 URL | 管理員限定 | 不進 sitemap，不提供公開轉址 |
| `/learn/*` | `/knowledge/*` 或保留路徑 | 選擇性改寫 | 公開知識可保留，但不得混入付費課程權限 |
| `/tech/*` | `/knowledge/ai/*`、`/courses/*/skills/*` 或歷史保存 | 選擇性改寫 | 先判斷是公開知識、技能單張素材或過時內容 |
| `/alphago/*` | `/knowledge/go-ai/*` 或保留路徑 | 選擇性改寫 | 保留圍棋與 AI 的背景價值，確認版權與技術正確性 |
| `/animations/*` | `/knowledge/interactive/*` 或歷史保存 | 待判定 | 依維護成本與實際使用情境決定 |
| `/research`、`/intel`、`/apps` | `/knowledge/*` 或新主題頁 | 合併／重寫候選 | 需確認是否仍是共學營對外內容 |
| `/impact-report/2026` | `/association/history/impact/2026` | 歷史保存或重寫 | 報告中的免費與會員主張需先拆分 |

## 3. 對每個 URL 必須補齊的欄位

- 現有 URL 與實際部署狀態
- 是否被 sitemap 收錄
- GSC 曝光、點擊、canonical 與外部連結
- 新 URL 或歷史保存位置
- `301`、`canonical`、`noindex`、`410` 或保留的決定
- 頁面內容 owner、作者／人物／機構公開權利
- 轉址後的 title、description 與主要搜尋意圖

## 4. 目前禁止自動執行的項目

- 不直接新增 redirect 設定。
- 不直接刪除舊頁。
- 不把歷史人物頁自動改成新會員或學員頁。
- 不把舊教材自動改成付費課程教材。
