# 舊 URL 最終處置登錄表（第一版）

版本：0.1（2026-09-20）  
狀態：逐群組處置；需要流量與外部連結資料的項目保留待補欄位。

## 1. 已可直接判定的群組

| 舊 URL 群組 | 最終候選處置 | 新站去處／處理 | 理由 |
| --- | --- | --- | --- |
| `/about/internal/**` | C：不公開 | 管理員保存，不進 sitemap | 內部 SOP、財務、收據與行政資料 |
| `/about/members/**` | A：成員內容 | 成員區，逐頁保留或改寫 | 會員姓名與個人資料已獲授權公開 |
| `/about/activities/**` | B：歷史或案例 | 依活動、合作與作品分開處理 | 不應混入現行課程承諾 |
| `/about/locations/**` | B：歷史／協會資料 | 協會資料或歷史資料 | 需避免被理解成現行服務據點 |
| 舊合作頁的「不收費／無會員費」段落 | A：改寫；原文 B 保存 | 改成協會與共學營現行說明 | 與每課 6,000 元及會員規則衝突 |
| 舊站翻譯頁 | 暫不建立新語系 | 保留來源，不產生新語系 route | 本階段繁體中文優先 |

## 2. 需要逐頁補 URL 的群組

| 舊 URL 群組 | 暫定處置 | 必須補的資料 |
| --- | --- | --- |
| `/learn/**` | A 候選 | 搜尋意圖、內容更新、是否轉公開知識 |
| `/tech/**` | A 候選 | 是否轉公開知識或技能單張素材 |
| `/alphago/**` | A／B 候選 | 版權、技術正確性、長期用途 |
| `/animations/**` | A／B／D 待判定 | 瀏覽器支援、維護成本、實際使用量 |
| `/research`、`/intel`、`/apps` | 改寫／合併候選 | 外部連結、現行服務 owner、是否仍招生相關 |
| `/impact-report/2026` | B 或改寫 | 數據來源、年份、免費主張改寫 |

## 3. URL 決策欄位

每個逐頁項目要補：`old_url`、`new_url`、`disposition`、`redirect_status`、`canonical`、`indexing`、`owner`、`traffic_evidence`、`rights_status`、`reason`。

沒有新 URL 或外部流量證據的頁面，不自行設定 301 或 410；先標為待判定。
