# 舊站內容權利與公開狀態登錄表

版本：0.1（2026-09-20）  
狀態：待逐頁填寫；不代表任何人已同意新站公開。

## 1. 登錄目的

舊站的檔案存在不等於協會擁有將內容、姓名、照片、機構資訊或作品搬到新站的權利。會員個人資料已有公開授權；其他資料仍要有可追溯的確認結果。

## 2. 欄位

| 欄位 | 說明 |
| --- | --- |
| source_path | 舊站來源檔案或素材路徑 |
| subject_type | 協會／個人／機構／作品／影像／第三方資源 |
| subject_name | 內容涉及的對象 |
| data_kind | 姓名、職稱、照片、文章、作品、商標、聯絡方式或其他 |
| source_of_right | 原作者、協會製作、外部授權、公開資料或未知 |
| current_public_status | 舊站公開、登入後、內部或未知 |
| proposed_public_status | 新站公開、歷史公開、登入後、管理員限定或不公開 |
| consent_status | 會員個資：已授權；其他資料：已確認、待確認、拒絕、期限不明 |
| owner | 負責確認的人 |
| evidence | 同意紀錄、授權、來源連結或會議紀錄 |
| expiry_or_review | 授權期限或下次複查日期 |
| action | 改寫、保留、限制、撤下或待裁決 |
| reason | 決策理由 |

## 3. 優先登錄對象

1. `src/data/members.js` 與 `docs/about/members/` 的人物資料：放入成員區，不移到歷史資料。
2. `docs/about/activities/partners/` 的合作機構、商標與照片。
3. `docs/about/activities/videos.md` 與活動頁的影像、主持人與參與者。
4. `src/pages/impact-report/2026.js` 的人物、數字、照片與合作主張。
5. 學員未來自行上傳的作品、機構資訊與圖片。

## 4. 驗收條件

- 會員個資依既有公開授權進入成員區；其他資料沒有 `consent_status` 確認就不進入公開新站。
- 歷史保存與現行招生資料有不同的公開狀態。
- 學員撤回公開後，公開頁、搜尋索引與快取處理方式可追蹤。
- 作品、圖片與機構資訊能找到作者與公開決定的證據。
