# 舊站資料轉移規格（規劃版）

版本：0.1（2026-09-19）  
狀態：待盤點執行；本文件不代表已移動或刪除任何內容。

## 1. 目的

從現有 Docusaurus 網站挑選適合共學營新定位的資料，保存舊資料的歷史價值，同時避免把舊站的協會定位、頁面結構與過時承諾直接帶進新網站。

「轉移」包含兩種不同動作：

- **新站內容轉寫**：資料仍對現代訪客有用，改寫為繁體中文共學營內容。
- **歷史資料保存**：資料有回憶、查證或長尾價值，但不應成為新站主導內容；保存原文與來源，日後在適合位置調閱。

## 2. 來源範圍

第一輪盤點發現：現有公開來源約 140 篇繁中 docs、11 個語系來源、5 個自訂頁面、人物／活動／工具／研究／產業情報資料，以及靜態圖片與 SEO 產物。此數量是盤點基準，不代表全部都要搬遷。

目前不把下列資料直接當成新產品資料：

- `src/data/members.js` 的人物資料不等於已確認會員或新站學員。
- 舊站合作、免費參加、無會員費等文案與新收費模型衝突，必須改寫或封存。
- 舊站翻譯資料本階段保留作資料來源，不建立多語系頁面。
- 外部子網域與 Slack bot 不自動納入新站轉移。

## 3. 分類規則

### A：轉寫到新站

符合以下條件之一：

- 能直接支持共學營的價值、流程、課程或參與方式。
- 是仍會被學員使用的繁中教材，且內容可核對與更新。
- 是現有搜尋流量或外部引用的重要入口，改寫後仍有明確用途。

去處：公開頁面、課程教材、實作營說明、學員可見內容或新資料模型。

### B：保留為歷史調閱

符合以下條件之一：

- 能代表協會過去的活動、人物、合作或發展歷程。
- 新站不應主動推廣，但未來可能需要查證或回顧。
- 內容不適合直接改寫成共學營承諾，卻具有資料保存價值。

去處：歷史資料庫、受控的歷史索引或離線保存；公開與否另行標記。

### C：封存不公開，或轉為管理功能需求

- 私人資料、未核實名單、過期行政資訊與付款附件。
- 內部 SOP、財務、收據等資料本身不公開，但可作為新共學營管理後台的流程、欄位、狀態與稽核需求來源。
- 可能造成誤導、隱私或名譽風險，且沒有公開必要。

去處：原始資料放受限保存區；經整理的管理需求進入管理後台規格，不進入新站公開 sitemap。

### D：淘汰

- 重複、空白、無法驗證、已失效且沒有歷史價值的內容。
- 只有舊框架導覽用途、沒有獨立資料價值的頁面殼。

淘汰前必須保留來源 URL、判斷理由與必要的 redirect／替代頁決策。

## 4. 每筆資料的盤點欄位

| 欄位 | 說明 |
| --- | --- |
| source_path | 舊站來源路徑 |
| title | 原標題 |
| content_type | 教材／人物／活動／合作／研究／工具／行政／其他 |
| current_claim | 目前主張與承諾 |
| new_role | 新站角色；沒有角色就不搬 |
| disposition | A 轉寫、B 歷史、C 不公開、D 淘汰 |
| destination | 新 URL、課程、歷史索引或保存位置 |
| public_level | 公開、登入後、實作營內、管理員限定、不公開 |
| owner | 需要誰確認內容 |
| seo_action | 保留 URL、301、canonical、noindex 或無需處理 |
| privacy_risk | 是否包含個資、醫療、法律、付款或未授權影像 |
| reason | 為什麼採此處置 |

## 5. 優先處理順序

1. 舊首頁、協會介紹、合作與收費文案：先處理與新定位衝突的公開承諾。
2. 目前有搜尋曝光或外部引用的頁面：決定保留、改寫或轉址，避免無理由失去入口。
3. 教材與互動內容：判斷哪些能成為課程技能單張或歷史教材。
4. 人物、活動與作品資料：分開判斷作者同意、資料新鮮度與是否屬新站參與者。
5. 翻譯、重複與舊行政頁：本階段只保存來源，不建立新語系頁面。

## 6. 轉移驗收

- 每筆被轉移或淘汰的資料都有來源、去處與理由。
- 新站不再顯示已被取代的免費／無會員費承諾。
- 歷史資料不會被誤標成現行課程、會員或學員帳號資料。
- 個人、機構作者與作品公開狀態有可追溯的同意紀錄。
- 保留或改寫的 SEO 入口有對應 URL、canonical 或 redirect 決策。
- 未核實、私密或不應公開的資料不進入公開內容與 sitemap。

## 7. 尚未執行的工作

- 產生逐頁 inventory 與 disposition 表。
- 對照 GA4／GSC、外部連結與內容更新日期。
- 由內容負責人確認人物、合作與作品的公開權利。
- 決定歷史資料的儲存位置、格式、公開程度與調閱介面。

本規格不授權刪除舊站、不授權公開個人資料，也不授權開始 Astro 或 Cloudflare 實作。
