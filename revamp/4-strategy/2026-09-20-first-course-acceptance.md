# 第一門課垂直切片驗收清單

版本：0.1（2026-09-20）  
狀態：Phase 2 驗收規格；尚未執行測試。

本門課同時是第一位講師的正式試點：講師必須使用網站提交講師／開課申請，經管理員核准後填寫課程表單，完整走過 1 堂教學、3 堂實作、論壇佐證、Review／Outcome 與 TTQS 匯出流程。不建立特別的測試捷徑。

## 1. 報名與會員

- [ ] 講師先透過網站提交講師／開課申請，附上資格、經驗與初步課程資料。
- [ ] 未上過至少一門 6,000 元標準課程的帳號，不能提交講師／開課申請。
- [ ] 系統以既有課程參與紀錄驗證講師申請資格。
- [ ] 管理員可以要求補件、核准或拒絕，並保留完整審核軌跡。
- [ ] 未核准的講師申請不能建立正式課程或送出 TTQS 開課資料。

- [ ] 課程資料符合標準模型：1 堂主題教學、3 堂實作、1 個月、6,000 元。
- [ ] 開課表單已填妥 TTQS Plan／Design 欄位，並鎖定課程版本。

- [ ] 訪客能看到主題、講師、日期、費用 6,000 元與課程包含內容。
- [ ] 報名會產生唯一報名編號。
- [ ] 學員能將報名編號提供給協會 LINE@ 作為匯款紀錄識別。
- [ ] 協會管理員可以人工標記付款確認或退回補件。
- [ ] 首課付款確認後建立一年期會員資格與課程開通。
- [ ] 已有會員報名新課時不重複建立首課入會，但仍需支付 6,000 元。

## 2. 登入與帳號

- [ ] 學員可使用 LINE 登入。
- [ ] 學員可使用 Email 一次性連結登入。
- [ ] 經本人同意後，LINE 與 Email 對應同一帳號。
- [ ] 系統不會依顯示名稱、機構名稱或相同 Email 自動合併帳號。
- [ ] 報名、會員、課程、實作營與文章都指向正確帳號。

## 3. 教學與實作營

- [ ] 系統保存實際授課、三堂實作、教材版本、出席與討論紀錄，並可填入 TTQS Do 欄位。
- [ ] 課後可填寫反應、學習、應用與結果資料，產生 Review／Outcome 紀錄。
- [ ] 可匯出課程大綱、評核表對照、證據索引的 ODT／PDF，以及 CSV／JSON manifest。
- [ ] 講師、管理人員、學員各自只能填寫其角色允許的表單欄位。
- [ ] 學員可上傳課堂側拍；講師或管理人員可將照片關聯至場次與 TTQS 指標後納入證據索引。

- [ ] 未核款者看不到完整技能單張。
- [ ] 課程開通後，學員可以取得該課全部技能單張。
- [ ] 學員可以自行加入該課實作營，不需第二次人工確認。
- [ ] 實作營是討論區，成員可以自由發文與上傳圖片。
- [ ] 講師與學員可以編輯、撤回自己的內容。
- [ ] 講師可隱藏自己負責的實作營中其他學員內容。
- [ ] 協會管理員可隱藏內容、通知作者並處理申訴。

## 4. 會員到期與長期紀錄

- [ ] 會員一年到期後，不能報名新課。
- [ ] 會員到期後，既有課程、實作營、文章、圖片與討論紀錄仍可依原權限查看與互動。
- [ ] 會員續會不會建立新的帳號或刪除既有紀錄。

## 5. 推薦展示

- [ ] 實作營自由發文不需要講師認可。
- [ ] 作品要進推薦頁時，必須有講師認可。
- [ ] 作品要進推薦頁時，必須有作者公開同意。
- [ ] 作者撤回公開後，推薦頁不再公開，但原實作營紀錄依保存規則處理。

## 6. 安全與回退

- [ ] 未加入實作營的已開通學員看不到營內文章與圖片。
- [ ] 其他課程學員不能讀取本課技能單張或附件。
- [ ] R2 附件不能靠猜測 URL 直接取得。
- [ ] 所有管理員隱藏、通知、申訴與恢復操作有紀錄。
- [ ] 發生權限越界時可以停止動態功能，保留 GitHub Pages 公開站。
