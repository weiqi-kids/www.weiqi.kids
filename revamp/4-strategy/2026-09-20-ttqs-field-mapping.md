# TTQS 官方欄位逐項對照規格

版本：0.1（2026-09-20）  
狀態：欄位對照基準；正式送評前須以當年度官方檔案再做一次差異檢查。

## 1. 對照結論

官方「訓練機構版查核佐證文件資料表」不是只有 PDDRO 五個分類。它還要求文件抬頭與每筆佐證的來源定位。因此網站資料模型必須同時保存：單位名稱、申請案號、評核範圍、指標項目、內涵說明、常見／實際佐證資料、來源文件與頁碼。

官方「訓練機構版指標課程大綱」則要求單元名稱、學習目標、課程大綱、時數、效益／產出、教學方法與 TTQS 架構或指標對應。網站的課程表單會使用同名欄位，不以自訂欄位取代。

## 2. 官方表單欄位與網站欄位

## 2A. 表單填寫與佐證採集

| 填寫者 | 可填內容 | 需要的流程紀錄 |
| --- | --- | --- |
| 講師 | 課程需求、目標、大綱、時數、方法、技能單張、評量與成果檢討 | 草稿、送審、核准、修改版本與時間 |
| 管理人員 | 單位抬頭、申請案號、評核範圍、行政資料、講師確認、指標對照、佐證索引與匯出 | 操作者、核准人、鎖定版本、匯出版本 |
| 學員 | 自由發文、作品、圖片、課堂側拍與實作使用紀錄 | 上傳者、課程／場次、時間、說明、公開狀態 |

學員在論壇上傳的文章、作品、圖片與側拍都具備該課程的佐證資格，可以關聯至 Do、Review 或 Outcome。講師或管理人員只需補上內容、關聯指標與來源定位；匯出時可依評核範圍選擇要呈現的證據，但不能因未被選入某次匯出就否定其課程佐證身分。照片中的個人與可辨識資訊依協會既有公開授權及內容權利規則處理。

| 官方欄位 | 網站欄位 | 規則 |
| --- | --- | --- |
| 單位名稱 | `organization_name` | 從協會設定帶入；匯出時不可留白 |
| 申請案號 | `application_no` | 送評時由協會填入；尚未取得時明確標示「待填」，不可自行產生政府案號 |
| 評核範圍 | `evaluation_scope` | 例如年度、訓練類別、課程批次；開課時先選定範圍 |
| 項目 | `pddro_stage` | 固定使用 Plan、Design、Do、Review、Outcome |
| 評核指標項目 | `indicator_no`、`indicator_name` | 使用官方指標編號與名稱，版本化保存 |
| 內涵說明 | `indicator_interpretation` | 保存該課如何符合指標的說明，不只保存勾選狀態 |
| 常見參考佐證資料 | `evidence_items` | 列出本課實際提交的文件或紀錄 |
| 資料來源及頁碼 | `source_document`、`source_page` | 每一筆證據都要有文件名稱／版本與頁碼或段落；網站連結只能作輔助 |

## 3. 課程大綱欄位

每門標準課程的 1 堂教學與 3 堂實作都要有下列資料：

| 官方課程大綱欄位 | 網站欄位 |
| --- | --- |
| 單元名稱 | `unit_name` |
| 學習目標 | `learning_objectives` |
| 課程大綱 | `syllabus` |
| 時數 | `hours` |
| 效益／產出 | `expected_outputs` |
| 教學方法 | `teaching_methods` |
| TTQS 架構或指標對應 | `ttqs_indicator_links` |

## 4. PDDRO 指標資料

開課表單不是只填課程介紹。每一課都要能關聯以下資料：

- Plan 1–6：協會方向、對外訓練政策、核心訓練類別、品質管理文件、訓練計畫與行政／訓練管理能力。
- Design 7–11：需求與能力分析、課程設計、利害關係人參與、資源與講師選擇、訓練需求與計畫連結。
- Do 12–14：依計畫執行、學習移轉支持、訓練資料分類與系統化保存。
- Review 15–16：評量與分析、異常及矯正措施。
- Outcome 17–19：多面向成果、訓練系統功能／學員評價、客戶或市場價值。

## 5. 匯出驗收條件

在稱為「完全對齊」前，匯出器必須通過以下檢查：

1. 官方表單的每個固定欄位都有對應資料來源。
2. 官方指標編號與名稱以版本資料表管理，不由前端自行拼字。
3. `source_document` 與 `source_page` 在佐證資料表逐筆出現。
4. 空值、待補資料、缺件與不適用必須分開標示。
5. ODT／PDF 的欄位順序、標題、PDDRO 分組與官方模板一致；CSV／JSON 只是同一份資料的機器格式。
6. 官方模板更新時，舊匯出包仍可依原版本重現，不被新欄位覆寫。

目前已確認官方檔案的欄位結構與本對照表；尚未建立匯出器，因此尚不能宣稱已通過上述第 5 項的實際檔案比對。
