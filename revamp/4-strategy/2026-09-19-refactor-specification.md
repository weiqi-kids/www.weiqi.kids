# 共學營網站重構規格（規劃版）

版本：0.1（2026-09-19）  
狀態：訪談後規格草案；不代表已核准實作。

## 1. 目標

將現有協會官網整理成繁體中文優先的 AI 共學營網站。網站要讓訪客理解共學營、完成課程報名，讓已核款學員取得課程內容，讓實作營成員在網站長期發文、上傳作品與互動。協會仍是主辦者；共學營不是另一個法人組織。

本次重構同時處理兩條線：

1. 舊站資料挑選、改寫與保存。
2. 新的公開網站、帳號、課程權限與實作營討論功能。

多國語系延後，舊站不原樣搬遷；範圍理由見 [ADR 0006](../../docs/adr/0006-traditional-chinese-first-and-archive-old-site-data.md)。

## 2. 已確認的產品規則

| 領域 | 規格 |
| --- | --- |
| 課程價格 | 每課 6,000 元；首次包含入會與首課；後續每課同價；既有協會人員報課也同價 |
| 會員期限 | 協會會員一年一續會；到期不刪除既有課程、作品或實作營討論紀錄；新課報名需有有效會員資格 |
| 課程內容 | 1 堂主題教學、全部技能單張與 3 堂實作；合計 1 個月；完整單張提供給已開通該課的參與者；不另收實作費 |
| 報名收款 | 網站報名產生報名編號；學員將編號附在 LINE@ 匯款紀錄；協會人工核款 |
| 開通 | 協會確認收款後人工開通該課教材；新學員首課開通時同步取得會員資格 |
| 登入 | LINE 與 Email 對應同一位學員帳號；Email 使用一次性登入連結；兩種登入綁定需學員同意 |
| 參與單位 | 個人各自報名與持有帳號；機構資訊可顯示，但公開由學員決定 |
| 實作 | 已取得該課資格的學員參與 3 堂實作討論，不需第二次協會確認 |
| 討論區 | 實作營就是討論區；學員可自由發文、上傳圖片與作品，不需事前審核 |
| 長期互動 | 課程結束、甚至停止會員後，原成員仍可登入、查看、發文、上傳與互動；講師回覆依意願 |
| 內容管理 | 講師與學員可編輯、撤回自己的內容；講師是實作營版主，可隱藏其他學員內容；協會管理員可管理並處理申訴 |
| 公開權 | 作品或機構資訊可公開，但由學員決定；撤回公開不刪除營內歷史紀錄 |

## 3. 目標資訊架構

### 公開層

- 共學營首頁：說明跨產業 AI 共學、每月主題、教學、實作營與參加方式。
- 課程／主題列表：公開主題介紹、講師、時間、費用、包含內容與報名入口。
- 技能單張閱讀層：完整單張僅提供給已開通該課的參與者；公開層只展示主題介紹。
- 公開作品／推薦展示：與討論區分開；不影響學員自由發文。
- 協會與歷史資料：說明主辦者，會員放在成員區；必要時提供活動、合作與舊站資料調閱入口。

### 登入後層

- 我的帳號：LINE／Email 綁定、個人與可公開的機構資訊。
- 我的課程：報名、開通狀態、教材與報名編號。
- 實作營討論區：文章、圖片、作品與持續互動。
- 內容管理：作者編輯／撤回；管理員隱藏／通知／申訴。

這是資訊架構草案，不是已決定的首頁文案或視覺設計。

## 4. Cloudflare 技術邊界

| 元件 | 責任 | 不負責 |
| --- | --- | --- |
| Astro | 繁中公開頁面與互動介面 | 不直接保存權限真相 |
| Workers | API、LINE callback、Email magic link、權限檢查、內容操作 | 不把單一 Access cookie 當成課程資格 |
| D1 | 學員、登入綁定、報名、會員、課程、實作營、文章、申訴 | 圖片與大型附件 |
| R2 | 作品圖片與附件 | 課程權限與文章狀態 |
| Access | 協會管理員後台與內部工具的入口 | 學員課程／實作營細部授權 |
| GitHub Pages | 現況靜態部署，待遷移期間保留回退 | 動態登入與討論資料層 |

Cloudflare Access 的 OIDC 與 token 驗證能力可作為管理入口；學員登入與課程授權仍由 Worker + D1 的應用規則完成。Email magic link 不直接等同 Access OTP。

## 5. 分階段交付

### Phase 0：規格與資料盤點

- 完成舊站資料分類表與來源 URL 清單。
- 完成 D1／R2 資料模型草案與權限矩陣。
- 確認 Cloudflare 帳戶、DNS、方案與部署回退。
- 驗收：所有 P0 流程有明確狀態、資料去處與失敗處理；沒有開始正式登入或收款。

### Phase 1：繁中公開網站

- Astro 7 公開頁面、課程介紹與報名入口。
- 舊站資料中核准保留的內容完成轉寫或歷史調閱入口。
- 保留必要 SEO URL、canonical、sitemap 與轉址策略。
- 驗收：訪客能理解產品、價格、資格、流程並提出報名；舊站資料不因遷移遺失。

### Phase 2：一門課的完整動態流程

- LINE／Email 登入與同帳號綁定。
- 報名編號、人工核款、首課／新課開通。
- 一門標準課程的 3 堂實作討論、圖片上傳、編輯、撤回、講師版主管理、通知與申訴。
- 驗收：用一門真實課程走完報名到持續互動，並驗證每個權限邊界。

### Phase 3：擴充與營運

- 多課程管理、管理員工作台、推薦展示與歷史資料調閱完善。
- 每門標準課程依 TTQS 訓練機構版 PDDRO 保存訓練紀錄，並可匯出官方表單對齊的 ODT／PDF 與 CSV／JSON；正式送評前確認當年度適用版本。
- 多國語系只有在繁中流程穩定且重新核准後才開工。

## 6. 本階段排除

- 不做多國語系、翻譯維護或語系子網域。
- 不原樣搬遷舊站頁面與導覽。
- 不把作品自由發文改成投稿審核流程。
- 不把 Astro 7 升級、設計系統、會員後端與內容遷移混成不可回退的一次變更。

## 7. 待盤點而非自行決定的項目

- 舊站每一類資料的去處與公開狀態。
- 未報名或未核款者不可見完整技能單張；歷史學員既有課程教材保留權限的細部規則。
- Email magic link 的寄信服務、有效期限與重發規則。
- 管理員隱藏、申訴恢復與資料保留期限。
