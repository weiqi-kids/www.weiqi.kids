# TTQS 政府格式匯出規格

版本：0.1（2026-09-20）  
狀態：規劃版；官方欄位對照見 [TTQS 官方欄位逐項對照](2026-09-20-ttqs-field-mapping.md)，實際匯出器尚未建立。

## 1. 匯出目標

每門課可以產出一個完整的課程稽核包，讓協會能以官方訓練機構版評核表與查核佐證文件資料表整理送評資料。匯出不依賴網站畫面，資料從有版本的課程紀錄產生。

## 2. 匯出檔案

| 檔案 | 用途 |
| --- | --- |
| `course-outline.odt` | 依官方課程大綱欄位產生：單元、學習目標、大綱、時數、效益／產出、教學方法、指標對應 |
| `ttqs-evaluation.pdf` | 依當年度官方評核表填入 PDDRO 指標與課程摘要 |
| `evidence-register.odt` | 依官方查核佐證文件資料表列出佐證名稱、說明、來源、頁碼與連結 |
| `evidence-register.pdf` | 供列印、寄送與封存的固定版面 |
| `records.csv` | 機器可讀的明細：課程、場次、學員、出席、教材、回饋、成果與事件 |
| `manifest.json` | 匯出時間、資料版本、官方表單版本、檔案雜湊、範圍與產製者 |

ODT／PDF 的欄位、標題、分組與順序必須逐項套用官方模板；CSV／JSON 是同一份資料的備份、查詢與重新產製格式。是否可直接上傳政府系統，必須等協會確認當年度官方收件規則後再決定。

## 3. 證據索引規則

每筆佐證至少包含：`evidence_id`、PDDRO 指標、文件名稱、文件版本、來源資料 ID、課程／場次、建立時間、操作者、頁碼或段落、附件連結、個資遮罩狀態與備註。匯出時依 PDDRO 與指標編號排序，缺件要列出缺件原因，不得靜默省略。

## 4. 開課到匯出的流程

1. 承辦人建立課程草稿，填完 Plan／Design 欄位。
2. 講師確認課程大綱、技能單張與 1+3 堂課的時程。
3. 協會核准後鎖定課程版本，才開放報名。
4. 執行期間持續寫入 Do 紀錄；討論區內容可自由新增、編輯、撤回或由版主隱藏，但事件紀錄保留。
5. 一個月結束後填寫 Review／Outcome，並標記尚未取得的追蹤資料。
6. 系統產生匯出包與 manifest；重新匯出建立新版本，不覆蓋舊包。
