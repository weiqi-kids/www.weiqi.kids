# TTQS 官方文件研究與適用基準

版本：0.2（2026-09-20）  
狀態：以目前官方最新版本作為第一門實際課程送評的規劃依據；不是 TTQS 通過或認證聲明。

## 1. 研究結論

本專案採用勞動力發展署目前公開的最新 **TTQS 訓練機構版**作為第一門實際課程送評的資料設計基準。協會的網站會保存該課從規劃、設計、執行、檢討到成果的可追溯紀錄，並依該版本產出官方評核表與查核佐證文件所需的欄位。

「符合欄位與佐證要求」不等於協會已取得 TTQS 認證。正式申請前，仍要向勞動力發展署或受託顧問確認協會的適用版本、送評資格與當年度表單版本。

## 2. 官方來源

以下只採用勞動力發展署 TTQS 官方網站的文件；實作時以官方頁面上的最新檔案為準。

| 文件 | 用途 |
| --- | --- |
| [TTQS 資料下載](https://ttqs.wda.gov.tw/ttqs/menu_010_new.php) | 下載作業要點、標準作業手冊、指引手冊、評核表、查核佐證文件資料表與課程大綱 |
| [評核表下載頁](https://ttqs.wda.gov.tw/ttqs/menu_010_02.php?type_id=4) | 取得訓練機構版 PDDRO 評核指標 |

| 訓練機構版「指標課程大綱」 | 課程單元、學習目標、大綱、時數、效益／產出、教學方法與指標對應欄位 |

## 3. PDDRO 對應

| 階段 | 官方指標 | 本網站必須保存的核心證據 |
| --- | --- | --- |
| Plan | 1–6 | 協會方向與訓練政策、需求分析、年度／主題計畫、訓練管理責任 |
| Design | 7–11 | 能力差距、學習目標、課程設計、利害關係人意見、講師與資源選擇 |
| Do | 12–14 | 實際授課、教材與學員紀錄、學習移轉支持、訓練資料分類與歸檔 |
| Review | 15–16 | 評量與分析、異常處理、矯正與預防措施、課程檢討 |
| Outcome | 17–19 | 反應、學習、行為／應用、結果、學員與市場價值 |

## 4. 對本專案的限制

1. 官方文件是評核與佐證的依據，不是要求網站照抄某一種畫面。
2. 政府目前提供可下載的 PDF／ODT 表單；在未確認是否存在政府匯入 API 或固定電子交換格式前，不能宣稱網站可直接匯入政府系統。
3. 因此本案的「政府格式」定義為：依目前最新官方版本填入官方表單欄位的 ODT／PDF，另提供 CSV／JSON 作為資料交換與稽核備份，並保留每筆證據的來源、頁碼、時間、版本與操作者。
4. 每次表單版本變動都要建立版本紀錄，不覆寫過去已送出的課程資料。
