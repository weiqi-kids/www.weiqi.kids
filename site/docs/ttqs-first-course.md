# 第一門課 TTQS 手動整理流程

依 ADR 0010，第一門課的 TTQS 資料以手動整理為主，不使用自動匯出器。網站提供兩項資料來源：課程論壇與技能單張的紀錄，以及管理區的佐證索引 CSV。欄位定義以 `revamp/4-strategy/2026-09-20-first-course-ttqs-form-draft.md` 為準。

## 開課前（Plan／Design）

1. 講師在網站提出講師申請（`/account/teaching/`），管理員在 `/admin/instructors/` 核准。
   - 第一門課沒有人上過課，無法滿足「先上過一門課」的條件。管理員在 `/admin/courses/` 指定講師時填寫例外理由，理由會寫入操作紀錄。
2. 講師與協會依表單草稿第 2～4 節填寫課程基本資料、Plan、Design，存成試算表或官方 ODT 範本。
3. 把課程寫進 `site/src/content/courses/<slug>.md`（`status: open`，4 個場次：第 1 堂 `teaching`，第 2～4 堂 `practice`），部署後開放報名。
4. 講師在 `/camp/courses/<slug>/materials/` 上傳技能單張；每次修改會保留版本。

## 上課期間（Do）

- 每堂課後，講師在課程論壇發一篇場次紀錄文章：實際日期、時間、教材版本、出席人數、教學內容、異常與處理。
- 學員的文章、作品、圖片與課堂側拍都直接發在課程論壇。

## 結營後（Review／Outcome）

1. 管理員在 `/admin/courses/` 下載「TTQS 佐證索引（CSV）」。
2. 在試算表補上每筆佐證的 PDDRO、指標、場次、頁碼與個資遮罩狀態；撤回或隱藏的內容保留在索引中並註明狀態，不刪除。
3. 依表單草稿第 6～7 節填寫檢討與成果，最後依第 9 節的匯出前檢查逐項確認。
4. 送件格式以勞動力發展署當期官方檔案為準。

## 之後

第一門課跑完後，依實際填寫經驗決定哪些欄位要做成網站表單與自動匯出（ODT／PDF／CSV／JSON）。
