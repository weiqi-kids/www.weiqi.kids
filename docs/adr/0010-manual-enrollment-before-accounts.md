# ADR 0010：先開放報名表，會員帳號與論壇後做

- 狀態：已接受
- 日期：2026-09-22

## 背景

完整報名流程依賴帳號、登入綁定與權限系統。第一門課不必等這些完成才能收報名。

## 決策

- 第二期只做報名表：參與者填寫姓名、聯絡 Email、LINE 顯示名稱（選填）、欲報名課程與是否首次入會。
- Worker 產生報名編號（格式 `WK-YYYYMM-XXXX`），寫入 D1 `enrollments` 表，頁面顯示編號與 LINE@ 匯款指示。
- 協會人工在 LINE@ 對帳；對帳結果在第三期的管理區記錄。第二期以 `wrangler d1` 匯出查看。
- 報名表以 Turnstile 防濫用。
- TTQS 表單第一門課以 `revamp/4-strategy/2026-09-20-first-course-ttqs-form-draft.md` 手動填寫，不做自動匯出器。

## 後果

- 報名編號在第三期沿用，與帳號建立後連結。
- 第二期網站不保存匯款資料，符合 ADR 0005。
