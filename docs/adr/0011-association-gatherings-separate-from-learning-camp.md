# ADR 0011：好棋寶寶棋聚與 AI 共學營分開建模

- 狀態：已接受
- 日期：2026-09-20

## 背景

舊站把圍棋活動、同樂會、合作夥伴與課程混在「關於／活動」之下。棋聚是開放的圍棋交流，共學營是需會員資格與付費的課程，兩者規則不同。

## 決策

- 協會、好棋寶寶棋聚、AI 共學營是同層的三個服務入口。
- 棋聚使用獨立的活動模型與 `Event` 結構化資料；共學營課程使用 `Course`。
- 棋聚不使用共學營課程論壇，參加棋聚不取得共學營資格。

## 後果

路徑分別為 `/association`、`/gatherings`、`/camp`，見 `revamp/5-content-spec/2026-09-20-site-tree-v2.md`。
