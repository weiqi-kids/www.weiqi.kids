# ADR 0014：共學營自動運作，開團規則由講師設定

- 狀態：已接受
- 日期：2026-10-08
- 取代：ADR 0013 全部；ADR 0001「參與者須具會員資格」；ADR 0004 全部；ADR 0005「匯款紀錄只走 LINE@」；ADR 0012「講師須先上過一門課」

## 背景

講師都是各有本業、因 AI 與圍棋串起來的熱心人士，投入時間各不相同。平台要盡量自動運作，不靠協會持續經營。站主 2026-10-07～08 逐項確認以下規則；2026-10-08 更正了上課結構、核款與誘因資料。

## 決策

### 平台固定規則

- 講師必須是協會會員。成果、開團設定與 TTQS 開課表單送管理員審核，通過才公開。
- 送審前必填 7 項吸引學員的資料，每項附協會成果當範例：成果展示、用 AI 前後差在哪裡、學完能做出什麼、適合誰與基礎、講師本業與動機、做法說明、一張試閱技能單張。學員作品經講師認可與作者同意後自動加到成果頁。
- 每團固定 1 堂主題教學＋3 堂實作，1 個月。3 堂實作沒有固定上課時間，學員自己找題目、每週在課程論壇交進度；系統自動提醒第 1 週交題目、第 2 週交第一版、第 3 週交成果，沒做出成果沒有後果。
- 學員報名課程不需入會。常年會費 6,000 元全歸協會，不含課程。
- 團費最低 6,000 元，協會與講師各分 50%，整團結束後才付講師。
- 款項匯到協會帳戶。學員在網站填匯款日期與帳號末五碼，一律由管理員核款；講師只看得到自己團學員的核款狀態。
- 第 1 堂開課前可全額退款，開課後不退；講師取消或中途無法繼續，全額退款；退款由管理員手動匯回。
- 每一團都要符合 TTQS：開課表單、線上簽到、結束問卷、佐證匯出由系統自動處理。
- 一團結束後，該成果自動重新開放登記想學。
- 系統通知（滿人數、匯款期限、實作提醒、核款結果等）用網頁推播（Web Push），同時留在帳號頁的站內通知；使用者沒開推播時只看得到站內通知。

### 講師自己設定（開團設定）

- 主題教學線上直播或實體上課（實體填地點；直播連結講師自己貼）。
- 團費（≥ 6,000 元）。
- 排時間方式：先填每週時段讓學員選（排在最近一週的該時段）／滿人數後講師提候選日期讓登記者投票，結果只供參考、由講師決定（講師 3 天內沒提出系統提醒，7 天沒提出這團不開）／預先訂日期。
- 滿人數後可以匯款幾天（預設 7）、投票開放幾天（預設 3），講師可以改。
- 成團條件：付款期限內付款滿人數才成團，未滿自動退款／登記滿人數就成團。
- 開團人數、人數上限（可不設；超過的人自動進下一團）。
- 成果的公開討論區預設開放，講師可關閉。

### 學員流程

看成果 → 照做法說明自己試（可在公開討論區問）→ 做不來就登記想學（登入、免費）→ 滿人數依講師設定排時間、匯款、成團 → 主題教學（簽到）→ 3 週實作交出成果 → 填問卷。

## 後果

- 仍需人工（都由管理員）：核款、退款匯回、成果上架審核、入會與續會核款、付講師分潤。
- 網頁推播的限制：iPhone／iPad 要 iOS 16.4 以上，且先把網站加到主畫面、從主畫面開啟才收得到；使用者拒絕或關掉瀏覽器通知權限就收不到；換手機或換瀏覽器要重新開啟。網站在詢問開啟推播的地方要寫出這些限制，iPhone 使用者另外顯示「加到主畫面」的步驟；帳號頁顯示目前這台裝置有沒有開推播。
- 網站多保存「匯款日期、帳號末五碼」兩個欄位，只有管理員看得到；匯款截圖仍不進網站。
- 2026-10-06 已部署到 staging 的版本（滿額通知管理員、開團人數寫在內容檔、報名綁會員）要依本決策重做。
- 實作（2026-10-08）：成果與團改存 D1，講師在講師後台自己建立；Worker 每小時排程推進每一團；舊的共學營頁面、內容檔與資料表全部移除。staging 改用新資料庫 `weiqi-kids-staging-camp`（帳號已搬過來；舊的 `weiqi-kids-staging` 於 2026-10-08 經站主同意刪除）。
- 沒有成團或講師沒排出日期時，登記名單不帶到下一團（否則同一批沒付款的人會立刻又觸發開團）；系統通知登記者可以再登記。只有額滿的人會自動帶到下一團。
- 協會帳戶的匯款帳號放在 Worker 變數 `BANK_ACCOUNT_INFO`；沒設定時，頁面請學員向協會 LINE@ 索取。
