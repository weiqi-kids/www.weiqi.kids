# ADR 0014：共學營自動運作，開團規則由講師設定

- 狀態：已接受
- 日期：2026-10-08
- 取代：ADR 0013 全部；ADR 0001「參與者須具會員資格」；ADR 0004 全部；ADR 0005「匯款紀錄只走 LINE@」；ADR 0012「講師須先上過一門課」

## 背景

講師都是各有本業、因 AI 與圍棋串起來的熱心人士，投入時間各不相同。平台要盡量自動運作，不靠協會持續經營。站主 2026-10-07～08 逐項確認以下規則。

## 決策

### 平台固定規則

- 講師必須是協會會員。成果、開團設定與 TTQS 開課表單送管理員審核，通過才公開。
- 學員報名課程不需入會。常年會費 6,000 元全歸協會，不含課程。
- 團費最低 6,000 元，協會與講師各分 50%，整團結束後才付講師。
- 款項匯到協會帳戶。學員在網站填匯款日期與帳號末五碼；該團講師或管理員核款，誰先確認都算，管理員事後以銀行明細總對帳。
- 第 1 堂開課前可全額退款，開課後不退；講師取消或中途無法繼續，全額退款；退款由管理員手動匯回。
- 每一團都要符合 TTQS：開課表單、線上簽到、結束問卷、佐證匯出由系統自動處理。
- 一團結束後，該成果自動重新開放登記想學。

### 講師自己設定（開團設定）

- 投入方式：「4 堂固定課」（1 堂主題教學＋3 堂實作）或「1 堂直播加論壇」，兩種都是一團 1 個月。只公開做法的成果免費，不開團、不送 TTQS。
- 團費（≥ 6,000 元）。
- 排時間方式：先填時段讓學員選／滿人數後投票／預先訂日期。
- 成團條件：付款期限內付款滿人數才成團，未滿自動退款／登記滿人數就成團。
- 開團人數、人數上限（可不設）。
- 是否附做法說明；成果的公開討論區預設開放，講師可關閉。

### 學員流程

看成果 → 自己試（可在公開討論區問）→ 做不來就登記想學（登入、免費）→ 滿人數依講師設定排時間、付款、成團 → 上課、簽到、填問卷。

## 後果

- 仍需人工：核款、退款匯回、成果上架審核、入會與續會核款、付講師分潤。
- 網站多保存「匯款日期、帳號末五碼」兩個欄位，講師可看到自己團學員的這兩欄；匯款截圖仍不進網站。
- 2026-10-06 已部署到 staging 的版本（滿額通知管理員、開團人數寫在內容檔、報名綁會員）要依本決策重做。
