# ADR 0007：新站以 Astro 7 建置於 Cloudflare，分期上線

- 狀態：已接受
- 日期：2026-09-22

## 背景

完整規格包含公開網站、報名、LINE／Email 登入、課程論壇、隱藏與申訴、TTQS 匯出與 DNS 搬遷。若全部完成才上線，新站會長期停在規格階段；舊站的免費文案也會一直留在線上。

## 決策

- 新站程式放在 repo 的 `site/` 目錄，以 Astro 7 建置，部署為 Cloudflare Worker（靜態資產＋少量 on-demand 路由），帳戶 `weiqi.kids`。
- 舊 Docusaurus 站在切換前原地保留，繼續由 GitHub Pages 服務，作為回退。
- 分期：
  1. 公開靜態站：協會、棋聚、共學營介紹與課程主題、公開知識，含舊網址 301。
  2. 報名：網站表單產生報名編號，存入 D1；付款經 LINE@ 由協會人工確認。不建立會員系統。
  3. 登入與單門課程論壇：LINE／Email 登入、課程開通、論壇、圖片、隱藏與申訴，先以第一門課試跑。
  4. TTQS：第一門課以手動整理為主，流程穩定後才寫自動匯出。
- 設計規範沿用團隊 Astro 守門：OKLCH token、字級階梯 ≥18px、單一 CSS 白名單、禁外部 CDN、去 AI 腔內容檢查。

## 後果

- 每期可獨立上線與回退；後期功能不阻擋前期上線。
- 正式網域 `www.weiqi.kids` 的切換是獨立操作，需站主確認後才執行。
- 取代 `2026-09-20-cloudflare-migration-plan.md` 中「Pages 或 Workers 待定」的部分。
