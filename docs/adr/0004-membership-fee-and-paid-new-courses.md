# ADR 0004：入會費含首課，後續每門新課另行付費

- 狀態：已接受
- 日期：2026-09-19

## 背景

舊站文案寫「免費參加」「無會員費」，與協會實際收費方式衝突。

## 決策

- 每門標準課程 6,000 元。
- 新參與者首次付款 6,000 元，同時取得會員資格與第一門課，不重複加收。
- 後續每門新課 6,000 元，既有協會人員同價。
- 會員資格一年一續會；到期只影響新課報名資格，不刪除既有課程、作品與討論紀錄。
- 一門課的費用涵蓋該課主題教學、全部技能單張與自選加入該課實作營，不涵蓋其他課程。

## 後果

- 舊站免費／無會員費文案須改寫或封存，才能進入新站公開內容。
- 續會付款確認流程見 `revamp/4-strategy/2026-09-21-remaining-spec-completion.md`。
