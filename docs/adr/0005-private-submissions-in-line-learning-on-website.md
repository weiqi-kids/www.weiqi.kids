# ADR 0005：匯款與私密資料走協會 LINE@，學習活動在網站

- 狀態：已接受
- 日期：2026-09-19

## 背景

協會目前以人工核對匯款。網站若直接收匯款截圖或身分文件，需要額外的保存與隱私責任。

## 決策

- 參與者附報名編號，經協會 LINE@ 提交匯款紀錄與其他私密資料。
- 協會人工核款後開通課程；新參與者首課開通時同步完成入會確認。
- 教材、作品、討論在網站進行。
- 網站提供 LINE 與 Email 登入，兩種方式對應同一位參與者的帳號；不依 Email 或名稱自動合併。

## 後果

- 網站只保存報名編號、付款狀態等管理必要欄位，不保存匯款截圖。
- 提交匯款紀錄不等於付款已確認，也不等於課程已開通。
