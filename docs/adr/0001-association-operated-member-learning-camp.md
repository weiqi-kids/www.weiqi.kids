# ADR 0001：共學營由協會主辦，參與者須具會員資格

- 狀態：已接受
- 日期：2026-09-19

## 背景

新網站以「AI 共學營」為主要服務，但主辦與會員關係一直屬於台灣好棋寶寶協會。若把共學營寫成獨立組織，會員資格、收費與對外責任會失去歸屬。

## 決策

- 協會是主辦組織與會員身分所屬的組織；共學營是協會的一種服務，不是另一個法人。
- 參加新共學營課程須具協會會員資格。
- 每門標準課程為 1 堂主題教學＋3 堂實作，合計 1 個月。

## 後果

- 公開網站以協會為主辦者，共學營頁面不另設組織資訊。
- 課程、會員與付款資料都歸屬協會管理。
- 詞彙見 `CONTEXT.md` 的「協會」「協會會員」「共學營」。
