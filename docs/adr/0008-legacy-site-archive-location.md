# ADR 0008：舊站資料的保存位置（待決 D-06）

- 狀態：已接受
- 日期：2026-09-22

## 背景

ADR 0006 決定舊站保存為資料，但沒有決定放在哪裡。D-06 是動態功能實作前的必要決策。

## 決策

- 以 git tag `legacy-docusaurus-final` 凍結舊站最後一版原始碼與內容，作為不可變的來源快照。
- 切換正式網域前，舊站檔案原地保留（`docs/`、`i18n/`、`src/`、`static/`），GitHub Pages 繼續服務作為回退。
- 切換並度過回退窗口後，舊站檔案移至 `archive/legacy-site/`，不參與新站建置、不公開部署。
- 新站需要引用舊站內容時，從來源快照轉寫進 `site/src/content/`，並在 frontmatter 記錄 `legacySource`（舊站檔案路徑）。
- 內部 SOP、財務與收據不進新站公開內容，只存在於來源快照；日後管理區若需調閱，從快照讀取。

## 後果

- 不需要額外的資料庫或匯出檔即可保存舊站。
- 舊站圖片與附件隨快照保存；新站只複製實際使用的檔案。
